# CO₂-Footprint-Webanwendung
Dieses Projekt wurde im Rahmen der Fallstudie im Modul Programmierung von Webanwendungsoberflächen (IPWA01-01)
an der IU Internationalen Hochschule entwickelt.

Die Webanwendung dient der übersichtlichen Gestaltung fiktiver CO₂-Emissionsdaten verschiedener Unternehmen
und Länder.

Verwendete Technologien:
- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3

Funktionen:
- Darstellung fiktiver CO₂-Emissionsdaten in einer Tabelle
- Filterung nach Ländern
- Suchfunktionen für Unternehmen
- Sortierung nach Land, Unternehmen und Emissionsmengen
- Zurücksetzen der Filter
- Responsives Layout für unterschiedliche Bildschirmgrößen
- Unterstützung einer manuell gesetzten Rechts-nach-links-Schreibrichtung (RTL)

Lokale Ausführung
1. Repository herunterladen oder klonen
2. Die Datei index.html in einem Webbrowser öffnen.
3. Alternativ das Projekt in Visual Studio Code über die Erweiterung Live Server starten.

Für Bootstrap und Google Fonts wird eine Internetverbindung benötigt.

Hinweise

Alle dargestellten Emissionsdaten sind fiktiv und dienen ausschließlich der Veranschaulichung.

Das Projekt wurde zu Studienzwecken erstellt.
